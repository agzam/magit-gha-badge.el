* 0.5.0
- While a run is going, the badge lists each running job with its current step and each failed job with the step that failed, failed jobs first. A finished red run keeps its failed jobs; a green run goes back to the single line. Past five jobs, four lines and =+N more=.
- =TAB= collapses the job lines, and =RET= on a job line opens that job's page.
- A branch that turns out to have no runs no longer leaves an empty line where the badge was.

* 0.4.0
- A failed fetch says why on the badge line: =Checks   ❗ 401 Bad credentials=, after the last known run when there is one. The tooltip holds the full error, =magit-gha-badge-browse-run= says why too, and the echo area shows each new error once.
- A missing token, a missing =github.user= or no network no longer stops magit from drawing the rest of the status buffer.
- A GitHub remote the token cannot read shows its error where it showed nothing. =magit-disable-section-inserter= in =.dir-locals.el= hides the badge for one repo.

* 0.3.0
- The badge says how long ago the run started: =Checks   🟢 CI 0ecbb23 - 5 minutes ago=.

* 0.2.0
- Find the runs of a pull request from a fork: the upstream repo is asked as well, narrowed to runs whose head repo is the fork, and the badge names the repo a run happened in when it is not the one the branch pushes to.
- =magit-gha-badge-browse-run= (and =RET= on the badge) refetches before it opens anything, instead of opening the run the badge happens to hold.
- Keep polling while a pushed commit has no run yet, bounded to three fetches, and mark the stale badge with a trailing ellipsis.

* 0.1.0
- Initial release: badge section in magit-status, async ghub fetch, bounded pending-poll, =magit-gha-badge-browse-run=.
